# That Which Lurks

## Chosen Platform
VR

## Instructions
Run the program from a Meta Quest VR project

## Mechanics
- Pickup the headlight to equip it
- Grab doorknobs to open doors
- Pick up and carry keystones
- Insert all the keystones to escape
- Pick up and throw rocks to solve a physics puzzle
- Pull a lever to open a gate
